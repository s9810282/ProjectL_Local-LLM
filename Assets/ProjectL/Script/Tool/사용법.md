# 전투 스테이지 편집 도구 사용법

Unity 에디터 안에서 맵과 유닛 배치를 편집하고, 결과를 엑셀로 저장하는 도구입니다. 이 문서는 HTML 도구가 아닌 **ProjecL 에디터 창** 기준입니다.

## 1. 창 열기

Unity 상단 메뉴에서 **ProjecL → 전투 스테이지 편집**을 선택합니다.

Project 창에서 에셋을 우클릭한 뒤 **ProjecL → 전투 스테이지 편집**으로 열어도 됩니다. 열린 창은 다른 Unity 탭 옆에 도킹할 수 있습니다.

## 2. 화면 구성

| 위치 | 역할 |
|---|---|
| 왼쪽 | 접을 수 있는 유닛 구역과 장애물·벽 / 타일 구역 |
| 가운데 | 3D / 2D 맵과 편집 도구 |
| 오른쪽 | 맵·선택 타일 정보, 유닛 정보, 장애물 정보 |

정보는 Unity Inspector가 아니라 **이 툴창의 오른쪽 영역**에 표시됩니다. 오른쪽의 **맵 · 타일 정보 / 유닛 정보 / 장애물 정보** 탭으로 전환할 수 있습니다.

왼쪽 구역 제목의 화살표 또는 제목을 클릭하면 펼치거나 접을 수 있습니다. 접어도 맵의 유닛이나 벽은 삭제·숨김 처리되지 않습니다.

- **유닛**: 현재 DT 유닛 목록과 배치 목록을 각각 펼치거나 접습니다.
- **장애물 · 벽 / 타일**: ObstacleMaster 기반 장애물 목록, 편집 도구, 배치된 벽 목록을 각각 펼치거나 접습니다.
- **현재 DT 장애물 목록**: 원본 ObstacleMaster의 이름·키·생명력을 표시합니다. 항목을 선택한 뒤 맵을 클릭·드래그하면 해당 장애물이 벽으로 배치됩니다.
- **배치된 벽 목록**: 이미 배치된 Blocked 타일을 표시합니다. 좌표를 클릭하면 해당 타일이 선택되어 오른쪽에서 높이·종류·Terrain 키·Obstacle을 수정할 수 있습니다.

오른쪽의 **전체 맵 / 선택 타일 정보 / 맵 설정**도 각각 접을 수 있습니다. 접기는 화면 정리용이며 엑셀 데이터에는 영향을 주지 않습니다.

## 3. 처음 만드는 순서

1. 상단 **새 맵**을 누릅니다. 기존 편집 내용이 있다면 먼저 엑셀로 저장하세요.
2. 상단 **맵 정보**를 누르고 오른쪽에서 Stage 키, 이름, 맵 크기를 설정합니다.
3. **맵 설정 적용**을 누릅니다. 설정값을 입력만 하면 맵에 적용되지 않습니다.
4. 왼쪽 **현재 DT 유닛 목록**에서 배치할 유닛을 선택합니다.
5. 가운데 맵의 비어 있는 바닥을 클릭합니다. 선택한 유닛이 배치됩니다.
6. 필요하면 높이, 벽, 레일 등을 편집합니다.
7. 상단 **엑셀 내보내기**로 배치 파일을 저장합니다.

예를 들어 가로 8, 세로 10, 아군 배치 깊이 2, 적군 배치 깊이 2로 시작할 수 있습니다. Stage 키는 양의 정수, 이름은 비어 있지 않은 값으로 입력하세요.

## 4. 유닛 엑셀 읽기

창을 열면 프로젝트의 다음 원본 DT를 자동으로 읽습니다.

- `Assets/DataTable/CharacterMaster.xlsx`: 유닛 목록과 능력치, 진형
- `Assets/DataTable/MethodMaster.xlsx`: 이동·공격 방식 정보
- `Assets/DataTable/ObstacleMaster.xlsx`: 벽으로 배치할 장애물 목록과 정보

다른 파일을 사용하려면 왼쪽 **유닛 엑셀 읽기** 또는 **Method 엑셀**을 누릅니다. `.xlsx` / `.xls`를 읽을 수 있으며, 파일 안에 각각 `CharacterMaster` / `MethodMaster` 시트가 있어야 합니다.

장애물은 **장애물 엑셀 읽기**로 다른 파일을 선택할 수 있습니다. 파일 안에 `ObstacleMaster` 시트와 양의 정수 `Obstacle_Key`가 필요합니다. 실제 데이터 행이 없다면 장애물 목록도 비어 있습니다. `TerrainMaster`는 이 장애물 목록의 원본이 아니며 Terrain 키와 Obstacle 키는 별도로 저장합니다.

프로젝트 원본을 수정했다면 엑셀 파일을 저장한 뒤 **프로젝트 DT 다시 읽기**를 누르세요. 이 버튼은 사용자 지정 파일 대신 위 프로젝트 경로의 DT를 다시 읽습니다.

유닛 목록에는 원본 DT의 실제 데이터 행만 표시됩니다. 헤더와 설명만 있고 유닛 데이터가 없다면 목록이 비어 있는 것이 정상입니다.

### 아군 / 적군은 DT로 결정

툴에서 아군·적군을 따로 선택하지 않습니다. `Character_PositionType` 값을 사용합니다.

| DT 값 | 진형 |
|---|---|
| 1 | 아군 |
| 2 | 적군 |

진형이 없거나 다른 값이면 새로 배치할 수 없습니다. 원본 DT에서 수정한 뒤 다시 읽어 주세요. DT를 다시 읽으면 이미 배치된 유닛의 진형도 현재 DT에 맞춰 갱신됩니다.

## 5. 유닛 배치와 정보 확인

### 배치

왼쪽 목록에서 유닛을 클릭하면 오른쪽에 유닛 정보가 표시되고 **유닛 배치** 도구가 선택됩니다. 맵의 빈 바닥을 클릭해 배치합니다.

- 검색으로 이름, Character 키, 진형, 직업을 찾을 수 있습니다.
- 같은 종류의 유닛을 여러 번 배치할 수 있습니다. 각 배치에는 별도의 Unit 키가 생깁니다.
- 한 타일에는 유닛 하나만 배치할 수 있습니다. 벽이나 맵 밖에는 배치할 수 없습니다.
- Character 키를 직접 입력하는 대신 현재 DT 목록에서 선택합니다.

### 선택 / 이동 / 삭제

1. 가운데 **선택 / 이동** 도구를 누릅니다.
2. 맵의 유닛이나 왼쪽 **배치 목록** 항목을 클릭합니다.
3. 빈 바닥을 클릭하면 선택한 유닛을 그 위치로 이동합니다.

오른쪽 **유닛 정보 → 배치 정보**의 X, Y를 수정해 이동할 수도 있습니다. 삭제하려면 **선택 유닛 삭제** 또는 Delete 키를 사용합니다. Delete는 입력 필드를 편집하고 있지 않을 때 동작합니다.

### 정보 확인

오른쪽에는 Character 키, DT 진형, 능력치, 이동·공격 방식과 추가 DT 정보가 표시됩니다. 배치한 유닛을 선택하면 Unit 키, 좌표, 배치 타일 높이도 확인할 수 있습니다.

능력치와 진형은 읽기 전용입니다. 변경하려면 원본 유닛 엑셀을 수정하고 다시 읽으세요. **원본 Character DT 전체 정보**를 펼치면 원본 필드 전체를 볼 수 있습니다.

**표시 색상**은 툴에서 수정할 수 있습니다. 같은 Character 키의 유닛에 함께 적용되며, 원본 DT를 수정하지는 않습니다.

## 6. 맵과 타일 편집

| 도구 | 사용법 |
|---|---|
| 타일 선택 | 타일을 클릭해 오른쪽에서 상세 확인·수정. 유닛이 있는 칸도 선택 가능 |
| 높이 | **칠할 높이**를 정한 뒤 클릭·드래그 |
| 바닥 | 클릭·드래그로 바닥 타일로 변경 |
| 벽 | DT 장애물 목록에서 항목을 선택한 뒤 클릭·드래그로 배치. 유닛이 있는 칸은 변경 불가 |
| 레일 | 클릭·드래그로 레일 타일로 변경 |
| 지우기 | 유닛이 있으면 유닛 삭제. 없으면 타일을 바닥·높이 0·Terrain 키 0으로 초기화 |

오른쪽 **맵 · 타일 정보**에는 전체 맵 미리보기와 선택 타일의 좌표, 높이, 타일 종류, Terrain 키가 표시됩니다. 작은 전체 맵에서도 타일을 클릭해 선택할 수 있습니다.

벽에 연결된 **Obstacle**은 드롭다운에서 변경합니다. 장애물 목록을 선택하면 오른쪽 **장애물 정보**에서 생명력·피격 효과·파괴 효과·효과 적용 지점·설명 키를 확인할 수 있습니다. 원본 값은 읽기 전용입니다. 벽을 바닥이나 레일로 바꾸면 Obstacle 연결은 해제됩니다. 높이만 바꿀 때는 연결을 유지합니다.

타일 종류의 저장 값은 `Floor`(바닥), `Blocked`(벽), `Rail`(레일)입니다. Terrain 키는 0 이상으로 입력합니다. 높이는 0~20이며, 유닛의 높이는 배치된 타일을 따릅니다.

좌표 `(0, 0)`은 맵의 왼쪽 아래입니다. 오른쪽으로 갈수록 X, 위쪽으로 갈수록 Y가 커집니다.

### 맵 크기 변경

오른쪽 **맵 설정**에서 값을 바꾸고 **맵 설정 적용**을 누릅니다.

- 가로 타일: 1~40, 세로 타일: 3~40
- 아군·적군 배치 깊이: 각각 1 이상이며, 두 값의 합은 세로 타일 수보다 작아야 함
- 대기 슬롯과 밤 길이: 1 이상
- Seed: 저장되는 설정값이며, 이 도구에서 자동 맵 생성을 실행하는 기능은 아님

맵을 줄일 때 잘려 나갈 영역에 유닛이나 편집된 타일이 있으면 적용이 거부됩니다. 해당 유닛을 이동·삭제하고, 타일을 바닥·높이 0·Terrain 키 0으로 초기화한 뒤 다시 적용하세요.

## 7. 시점과 되돌리기

| 조작 | 기능 |
|---|---|
| 좌클릭 | 현재 도구로 선택·배치·편집 |
| 우클릭 드래그 | 3D 시점 회전 |
| 마우스 휠 | 3D 확대 / 축소 |
| Shift + 우클릭 드래그 또는 중간 버튼 드래그 | 3D 시점 이동 |
| 2D 보기 / 3D 보기 | 맵 표시 방식 전환. 두 방식 모두 편집 가능 |
| 시점 초기화 | 3D 시점을 맵 기준으로 초기화 |
| 되돌리기 / 다시 실행 | 편집 Undo / Redo |
| Esc | 선택 해제. 입력 필드 편집 중에는 적용되지 않음 |

타일을 한 번 드래그해서 칠한 작업은 하나의 되돌리기 단위입니다. 새 맵을 만들거나 다른 배치 엑셀을 열면 이전 편집 이력은 초기화됩니다.

### 이동·공격 범위

유닛을 선택한 뒤 맵 위의 **이동 + 공격 / 이동 / 공격 / 숨기기**로 표시를 바꿀 수 있습니다. Method DT의 형태를 바탕으로 범위를 미리 보여 줍니다.

이 표시는 실제 전투 판정이 아닙니다. 중간 장애물 경로, 유닛 점유, 단차, 행동비용, 시야, 스플래시 계산은 포함하지 않습니다. 방향 선택도 부채 범위의 미리보기용이며 배치 파일에 저장되지 않습니다.

## 8. 엑셀 저장과 이어서 편집

상단 **엑셀 내보내기**를 누릅니다. 기본 파일명은 `CombatLayout_<StageKey>.xlsx`, 기본 위치는 `Assets/DataTable`입니다. 한 파일에 한 스테이지를 저장합니다.

| 저장 시트 | 내용 |
|---|---|
| CombatStageMaster | 스테이지 설정 |
| CombatCellMaster | 전체 타일 정보 |
| CombatUnitMaster | 유닛 배치 정보 |
| EditorCharacterMaster | 읽어 온 유닛 정보와 표시 색상 사본 |
| EditorMethodMaster | 읽어 온 Method 정보 사본 |
| EditorObstacleMaster | 읽어 온 장애물 정보 사본 |

참조 정보 시트는 해당 DT를 읽었을 때 저장됩니다. 원본 `CharacterMaster.xlsx`, `MethodMaster.xlsx`, `ObstacleMaster.xlsx`나 기존 테이블 SO는 변경하지 않습니다. 장애물 키는 CombatCellMaster의 `CombatCell_ObstacleKey`에 저장하며 Terrain 키와 별개입니다.

다시 편집하려면 **엑셀 열기**로 저장한 배치 파일을 선택합니다. 파일의 표시용 DT 사본보다 현재 읽은 원본 DT를 우선합니다. 기존 SchemaVersion 1 배치는 그대로 열 수 있습니다. Obstacle이 연결된 배치는 SchemaVersion 2로 저장하므로 현재 Unity 도구에서 편집하세요. 이전 HTML 도구는 버전 2를 지원하지 않습니다.

스테이지 이름 옆의 `*`는 엑셀로 내보내지 않은 변경이 있다는 뜻입니다. 초안은 프로젝트별 EditorPrefs에 보관되어 창 재실행 시 복원할 수 있지만, 팀에 공유되는 파일은 아닙니다. **공유하거나 작업을 확실하게 남길 때는 엑셀로 내보내세요.**

## 9. 자주 막히는 경우

| 상황 | 확인할 내용 |
|---|---|
| 유닛 목록이 비어 있음 | 원본 파일 경로와 CharacterMaster 시트, 실제 유닛 데이터 행 확인. 엑셀 저장 후 다시 읽기 |
| 장애물 목록이 비어 있음 | ObstacleMaster 시트의 실제 데이터 행 확인. 엑셀 저장 후 다시 읽기 |
| 유닛을 배치할 수 없음 | 현재 DT 등록 여부, PositionType이 1 또는 2인지, 대상 타일이 벽·점유 상태인지 확인 |
| 이동·공격 방식 정보가 없음 | MethodMaster를 읽었는지, 유닛의 Method 키에 해당하는 행이 있는지 확인 |
| 맵 설정이 반영되지 않음 | **맵 설정 적용**을 눌렀는지 확인. 창의 오류 메시지에 따라 크기·배치 깊이 수정 |
| 맵을 줄일 수 없음 | 축소 영역의 유닛과 편집 타일을 먼저 정리 |
| 내보내기가 거부됨 | 원본 유닛·장애물 DT를 읽고, 기존 배치의 Character 키·진형·Obstacle 키가 현재 DT에서 유효한지 확인 |

DT에서 삭제되었거나 진형이 잘못된 유닛의 기존 배치는 자동으로 지워지지 않습니다. 원본을 수정하거나 해당 배치를 삭제한 뒤 내보내세요.

## 10. 게임 적용 범위

현재 도구는 **배치 편집과 엑셀 저장**까지 담당합니다. 배치 엑셀을 `Assets/DataTable`에 저장한다고 자동으로 SO가 만들어지거나 게임에 배치가 반영되지는 않습니다.

게임에 사용하려면 배치 데이터의 임포터·SO·조회 등록과 런타임 맵/유닛 생성 연결이 별도로 필요합니다. 자세한 데이터 계약과 구현 내용은 [README](README.md)를 참고하세요.
