# 유닛 통합 에디터 사용법

메뉴 **ProjectL → 유닛 통합 에디터**. 유닛(규칙 Unit SO + 외형 Visual SO)을 찾고, 고치고, 복제해서 새로 만들고, UnitRoster에 넣고 뺍니다.

## 화면
- **왼쪽 목록**: 검색(표시 이름·키 이름·파일 이름·번호), 전체/아군/적, "문제 있는 것만". 노란 느낌표는 문제가 있는 유닛입니다(마우스를 올리면 이유).
- **오른쪽**: 고른 유닛의 편집 화면, 또는 [+ 새 유닛]을 누르면 생성 화면. 두 칸 사이 경계를 끌어 너비를 바꿉니다.
- 목록은 프로젝트에서 에셋이 바뀌면 저절로 다시 읽습니다. 안 맞아 보이면 [목록 새로고침].

## 고치기
- 값을 바꾸면 바로 SO에 들어가고(Undo 가능) 이름 옆에 `*`가 붙습니다. **[검증 · 저장]**을 눌러야 파일에 저장됩니다.
- **[되돌리기]**: 저장하지 않은 변경을 파일 판으로 되돌립니다.
- 저장하지 않은 채 다른 유닛을 고르거나 창을 닫으면 저장/버리기/취소를 묻습니다.
- 검증에 실패하면 저장되지 않습니다(부트에서 DB 생성이 멈추기 때문). 이유는 위쪽 빨간 줄에 나옵니다.
- 짝 Visual이 없는 유닛은 규칙만 고칠 수 있고, [짝 Visual 만들기]로 다른 Visual을 복제해 붙일 수 있습니다.

## UnitRoster
- 편집 화면 "UnitRoster" 묶음에서 체크로 넣고 뺍니다. [검증 · 저장]이 로스터도 함께 저장합니다.
- **EnemyLoadout·증원 풀에 쓰는 적은 그 스테이지의 로스터에 있어야** 전투에 들어갈 수 있습니다. 그런 곳에서 쓰는 유닛을 빼려 하면 확인 창이 뜹니다.
- 아군(PlayerOnly)은 로스터 없이도 전투에 나옵니다.

## 새 유닛 만들기
1. [+ 새 유닛] → **원본 Unit**을 고릅니다. 문제가 있는 유닛은 원본 목록에 나오지 않습니다("원본으로 쓸 수 없는 유닛"에 이유).
2. 키: "새 enum 항목 추가"를 켜면 `EntityKey.cs`에 새 항목을 넣고 Unity 재컴파일을 기다린 뒤 이어서 만듭니다. 끄면 이미 있지만 SO가 없는 키를 고릅니다. 잘못된 키는 입력하는 동안 노란 줄로 보입니다.
3. 표시 이름(비우면 키 이름에서 `Unit_`을 뺀 값), 설명(비우면 원본 그대로), 진영 자격(비우면 원본 그대로).
4. 저장 폴더·등록 테이블, **등록할 UnitRoster**(원본이 든 로스터가 기본으로 체크됩니다. 아군 원본이면 비어 있음).
5. [생성 · 등록]. 위쪽에 진행 상태가 나옵니다.
- 프리팹·연출·특성은 원본과 같은 것을 가리킵니다. "원본과 함께 쓰게 되는 참조"에서 확인하고 생성 뒤 바꾸세요.
- 멈추면: [재검사 · 재개] 또는 [요청 취소 · 생성물 삭제](테이블·로스터 등록과 만든 SO를 지움, 추가한 enum은 남음). 원본이 요청 뒤 바뀌었으면 [바뀐 원본으로 계속]. Unity를 껐다 켜면 [재검사 · 재개]를 눌러야 이어집니다. 끝난 요청 줄은 [닫기]로 치웁니다.
- 작업 기록 파일이 깨지면 [기록 파일 열기]·[기록 버리기]. 버리기는 기록만 지우니 이미 만든 SO·등록은 직접 확인하세요.

## 유닛 삭제
편집 화면 맨 아래 [유닛 삭제…].
- 먼저 바뀌는 곳을 창으로 보여 줍니다: 빼는 테이블, 이 유닛을 쓰는 로드아웃·스테이지·로스터 칸(함께 뺍니다), 도구가 자동으로 못 빼는 다른 파일의 참조(삭제 뒤 Missing이 됨).
- [삭제]를 누르면 참조 칸 빼기(배열이면 그 줄을 지우고, 단일 칸이면 비움) → 테이블에서 빼기 → Unit·Visual SO를 휴지통으로 옮깁니다. Undo는 되지 않습니다(휴지통·버전 관리에서 복구).
- "EntityKey.cs의 enum 항목도 지우기"를 체크하면 그 줄도 지우고 재컴파일합니다. 코드나 다른 SO가 그 키를 쓰면 enum은 남기고 진행할지 묻습니다. 체크하지 않으면 키는 남아 다음 생성 때 "기존 미사용 키"로 다시 쓸 수 있습니다.
- 참조를 뺀 뒤 검증에 실패한 SO(예: 후보가 0개가 된 EnemyLoadout)는 Console에 경고로 남습니다.

## 쓰는 곳
편집 화면 맨 아래 "쓰는 곳"이 이 유닛을 참조하는 로드아웃·스테이지·로스터와 필드 경로를 보여 줍니다(읽기만, [찾기]로 프로젝트 창에서 표시).
