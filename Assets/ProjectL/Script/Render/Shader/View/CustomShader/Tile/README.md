# 월드 좌표 UV 타일

`WorldSpaceUV.shader`는 URP용 불투명 Unlit 셰이더다. 윗면은 월드 XZ 좌표의 텍스처와 평면 외곽 마스크, 벽면은 아래색→위색 그라데이션으로 표시한다. 같은 텍스처와 Tiling·Offset을 쓰는 타일은 월드 위치에 맞춰 윗면 무늬가 이어진다. 오브젝트 이동·Y축 회전·스케일 변경에도 무늬의 기준과 반복 크기는 월드에 고정된다.

## 사용

1. `WorldSpaceUV.mat`의 **World XZ Texture**에 반복할 텍스처를 넣는다. 기본값은 흰색이므로 텍스처를 지정해야 무늬를 볼 수 있다.
2. 타일의 MeshRenderer에 이 머티리얼을 적용한다. 여러 타일이 같은 머티리얼을 공유하면 설정도 함께 유지된다.
3. 텍스처 아래 **Tiling**으로 반복 밀도를, **Offset**으로 시작 위치를 조절한다. U는 월드 X, V는 월드 Z다.
4. 타일 두 개를 붙이고 하나를 이동하거나 Y축으로 회전해 무늬가 월드 기준으로 이어지는지 확인한다. 음수 X·Z 위치에서도 확인한다.
5. **Side Bottom Color / Side Top Color**로 벽면 아래·위 색을 지정한다. 높이 기준은 각 MeshRenderer의 월드 경계에서 자동으로 읽는다.
6. **Edge Mask Color**로 윗면의 외곽 마스크 색을 지정한다. 색의 **Alpha**는 해당 색을 덮는 강도다. `0`은 원래 텍스처, `1`은 마스크 색이다.
7. **Edge Mask Width (UV)**로 윗면 가장자리에서 안쪽으로 들어오는 폭을 지정한다. 기본 `0.03`은 한 변 UV 길이의 3%다. `0`이면 꺼진다. **Edge Mask Softness (UV)**로 경계 번짐을 조절한다.
8. **Preview Edge Mask**를 켜면 윗면에서 마스크 영역은 흰색, 내부는 검은색으로 확인할 수 있다. 확인 후 끄면 지정한 색으로 표시된다.
9. **Top Face Normal Y Threshold**는 윗면 판정 기준이다. 기본 `0.7`이며, 값이 높을수록 수평에 가까운 면만 윗면 텍스처로 표시한다. 베벨이 벽면 색을 쓰게 하려면 값을 높인다.

| Tiling (X, Y) | 텍스처 한 장의 월드 크기 (X, Z) |
|---|---|
| (1, 1) | 1 × 1 |
| (0.5, 0.5) | 2 × 2 |
| (0.25, 0.5) | 4 × 2 |

셰이더 메뉴는 **ProjectL → Tile → WorldSpaceUV**다. 기존 머티리얼의 Shader를 이 값으로 바꿔도 사용할 수 있다.

## 동작과 적용 범위

- UV 계산은 셰이더 한 곳에서 `worldPosition.xz * _BaseMap_ST.xy + _BaseMap_ST.zw`로 수행한다. 설정은 머티리얼이 소유하며 별도 C# 위치 갱신이나 Framework 서비스 등록은 필요 없다.
- 트릴리니어 Repeat 샘플러를 사용하므로 원본 텍스처의 Wrap Mode를 변경할 필요가 없다. 경계까지 자연스럽게 이어지는 무늬에는 타일링 가능한 원본 텍스처를 사용한다.
- 윗면은 월드 위쪽을 향하는 법선으로 판정한다. 월드 Y 높이는 윗면 UV에 영향을 주지 않는다. 나머지 면과 바닥에는 높이 그라데이션을 적용한다.
- 외곽 마스크는 **윗면 자체의 원래 UV0 사각형 경계**에서 계산한다. Unity Plane·Quad·Cube처럼 윗면이 UV `(0,0)`~`(1,1)`을 채우는 메시를 대상으로 한다. 위에서 내려다봐도 윗면 안쪽 테두리가 보이며, 벽면에 테두리 띠를 넣지 않는다.
- 마스크는 `min(U, V, 1-U, 1-V)`로 가장자리 거리를 구해 색을 덮는다. 월드 텍스처 Tiling·Offset은 이 마스크에 영향을 주지 않는다. 사각형이 아닌 메시 윤곽이나 텍스처 아틀라스의 UV 조각 경계를 자동으로 추출하는 기능은 아니다. 여러 사각형이 같은 UV를 공유하면 각 사각형에 같은 마스크가 생긴다.
- 높이는 Unity의 `unity_RendererBounds_Min/Max`를 사용한다([Unity Object 노드의 World Bounds 설명](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.0/manual/Object-Node.html)). 여러 타일을 하나의 MeshRenderer로 합치면 그 전체 높이를 기준으로 한다. CPU에서 정점을 변형하거나 커스텀 bounds를 사용하면 경계가 실제 메시와 일치해야 한다.
- 일반 GPU 인스턴싱 변형은 사용하지 않으며 Renderer별 경계를 읽는다. 재질 상수는 `UnityPerMaterial`에 모아 SRP Batcher의 배치를 유지한다.
- Unlit이므로 조명·그림자를 받지 않으며 그림자를 투사하지 않는다. 텍스처·윗면 Tint·벽면 색의 알파는 사용하지 않고 외곽 마스크 색의 알파만 덮는 강도로 쓴다. 결과 표면은 불투명하다. 불투명 깊이 쓰기와 DepthOnly 패스를 제공한다.
- 씬·프리팹 연결은 머티리얼을 지정하는 쪽에서 담당한다. UV 표현 수정은 이 셰이더, 텍스처·반복 설정 변경은 머티리얼 안에서 끝나며 Core·Buffer·다른 View 기능에 의존하지 않는다.

## 확인 기록 (2026-10-31)

- 이전 벽면 상단 띠 방식은 사용자 의도 정정에 따라 윗면 UV0 외곽 마스크로 교체했다. 외곽 마스크 색·Alpha·폭·번짐 및 흑백 미리보기를 제공한다.
- Unity 6000.0.73f1 / DX11의 큐브 미리보기에서 윗면 안쪽 테두리와 흑백 마스크를 번갈아 확인했다. 벽면은 높이 그라데이션을 유지하며 Console 오류·경고는 0개였다. 최종 상태는 색상 표시다.
- UTF-8·LF와 에셋의 `.meta` 쌍을 확인했다. 실제 대상 타일의 베벨·법선 및 씬 내 표시는 연결 후 확인한다.
