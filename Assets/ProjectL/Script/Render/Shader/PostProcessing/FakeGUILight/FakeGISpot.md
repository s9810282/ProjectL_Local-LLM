# FakeGI Spot

기존 FakeGI의 별도 Spot 셰이더입니다. 실제 Unity Light 컴포넌트와 자동 연동하지 않습니다.

## 사용

1. Sphere MeshRenderer에 `ProjectL_FakeGISpot.mat`을 할당합니다.
2. Unity 기본 Sphere(반지름 0.5)는 Light Radius가 5일 때 월드 스케일을 (10, 10, 10)으로 설정합니다. 투영용 메시가 조명 범위를 감싸야 합니다. 부모 스케일은 (1, 1, 1), 양수 균일 스케일을 권장합니다.
3. 오브젝트의 로컬 +Z(파란 화살표)가 빛이 향하는 방향입니다. 오브젝트 회전으로 조준합니다.
   표면 조명과 공중 빛줄기 모두 같은 월드 방향을 사용하며 부모 회전도 반영합니다. 원형 원뿔이므로 로컬 Z축 회전만으로는 모양이 달라지지 않습니다. 개별 오브젝트 변환을 보존하도록 셰이더 배칭을 비활성화했습니다. 움직이거나 회전할 광원 오브젝트에는 Static/Batching Static을 사용하지 마세요.
4. 내부 각도는 최대 밝기 범위, 외부 각도는 빛이 사라지는 범위입니다. 둘 다 전체 원뿔 각도이며 기본값은 30/50도입니다. 내부 각도가 외부 각도 이상이면 셰이더가 자동 제한합니다.
5. Light Radius / Falloff / Softness는 기존과 동일하게 거리 감쇠를 제어합니다. 반경을 늘리면 메시 크기도 늘려야 합니다.

기존 `FakeGI` 컴포넌트는 이 셰이더의 프로퍼티 이름과 일치하지 않는 바인딩을 사용하므로 붙이지 말고 머티리얼에서 직접 설정합니다.

## 렌더링 조건과 제한

- URP Depth Texture가 필요합니다. Accurate Colors를 사용하면 Opaque Texture도 필요합니다.
- Shading/Specular에는 카메라 노멀 텍스처를 생성하는 렌더 경로가 필요합니다.
- 원뿔 마스크는 기본 조명, Halo, Specular 모두에 적용됩니다. 중앙 발광 구체는 별도 장식 패스이며 기본 비활성화입니다.
- 이 머티리얼은 Halo와 방향광 감쇠를 기본 비활성화하여 원뿔 조명부터 확인하기 쉽게 구성했습니다.
- 실제 GI나 광원 기준 그림자는 아닙니다. 벽 너머 누광이나 투명 표면 등 기존 FakeGI의 제약이 남아 있습니다.
- 기존 FakeGI 셰이더/머티리얼 및 씬은 변경하지 않습니다.

## 공중 빛줄기

- `공중 빛줄기 사용`으로 활성화하고 `빛줄기 밀도`로 농도를 조절합니다. 기본 밀도는 0.15입니다.
- `빛줄기 샘플 수`는 기본 32이며, 높이면 경계 품질과 GPU 비용이 함께 증가합니다.
- 기존 표면 조명과 같은 색상, 세기, 반경, 원뿔 각도, 거리 Falloff, 방향광 감쇠를 사용합니다. 별도 노이즈/깜빡임/단계화 등 표면 장식은 빛줄기에 적용하지 않습니다.
- 카메라 near plane부터 원뿔 볼륨을 적분하고 불투명 씬 깊이에서 멈춥니다. 배경이 하늘이어도 빛줄기가 표시됩니다. Accurate Colors와 무관하게 공중에 색을 더합니다.
- 광원에서 샘플 지점까지의 그림자는 계산하지 않으므로 장애물 뒤쪽의 광원 누광까지 막지는 않습니다. 투명 물체는 보통 깊이에 기록되지 않아 빛줄기를 차폐하지 않습니다.
- 정상 방향의 닫힌 Sphere 메시를 사용하세요. 빛줄기는 뒷면에서만 한 번 합성하므로 카메라가 볼륨 안으로 들어가도 중복 가산하지 않습니다. 메시 전체가 카메라 far plane에서 잘리면 표시가 제한됩니다.
