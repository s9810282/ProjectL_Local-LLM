# results/playstyle — 플레이 성격 지표 결과

`sim/playstyle.py`가 전투 기록(`results/sim/…`)을 다시 돌려 센 지표와, `sim/playstyle_compare.py`가 낸 비교·표다.
설계와 실행 기록은 `docs/2026-11-18-enemy-playstyle-consistency-design.md`, `docs/2026-11-18-enemy-playstyle-knobs-design.md`(§0과 §13이 지금 상태).

폴더마다 `battles.csv`(판마다 지표의 분자·분모), `mismatch.json`(다시 돌린 기록이 저장된 것과 다른 판), `run.json`이 있다.
