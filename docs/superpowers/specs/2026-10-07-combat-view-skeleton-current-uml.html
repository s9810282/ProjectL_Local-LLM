입력 → Core → 결과 표시

확정 명령은 ViewBuffer를 지나 Job으로 처리됩니다. View는 연출과 후처리를 마친 뒤에만 결과 확인 번호를 올립니다.

Flow: Runner가 비고 이전 등록 확인이 끝난 경우에만 국면에 따라 명령 → 미리보기 → 자동 진행 중 해당 Job 하나를 등록합니다.

표시: ResultPlayback → OrderedPresentation → SceneDisplay 이후 Gate 해제·입력 삭제·결과 확인을 수행합니다. HUD 금액은 Core 상태의 StageGold입니다.
