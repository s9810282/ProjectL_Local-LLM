### 3.1 C10 정확성·오류 처리 (4)

1. **M-01 로비 입력 콜백의 예외가 오류 경계(F1)에 닿지 않는다**
   - 위치
     - `V/Lobby/LobbyInteraction.cs:63-94`
     - `V/Lobby/Deck/LobbyDeckPresenter.cs:69-92`
     - `V/ArtifactPopup/ArtifactPopupController.cs`의 `InputReceiver`

     - 다음 경로는 모두 런타임 Tick 밖의 InputSystem·EventSystem 콜백에서 돈다.
       - 시설 누름·뗌 → 이동
       - 아티팩트 끌기

     - 이 경로 어디에도 `RuntimeFaultBoundary.Report`가 없다. 같은 컨트롤러의 닫기 수신자(`CloseReceiver`)만 보고한다.

     - 프리팹 배율 × 모델 배율
   - 영향: 규칙을 한쪽만 고치면, 끄는 동안 보인 자리와 놓은 뒤 다시 그린 자리가 달라 놓는 순간 모델이 튄다.
   - 고칠 방향: "칸 목록 + 회전 → 로컬 자세" 함수 하나를 두 표시가 부른다.
   - 검증: 중간 / 중간

### 3.3 C13 UI 규약 (1)

6. **M-12 아티팩트 3D 표시가 로비 루트 참조가 빠져도 예외 없이 넘어간다**
   - 위치: `V/ArtifactPopup/ArtifactPopupView.cs:19-20·62-77·87-89`, `V/Lobby/LobbySceneRoot.cs:17·21`
   - 문제
     - 팝업 표시가 로비 공간 루트(`lobbyRoot`)를 직접 끄고 켠다. 참조가 null이면 건너뛰고, `Validate`는 이 칸을 보지 않는다.
     - 지금 씬에서 이 칸은 `LobbySceneRoot.worldRoot`와 같은 객체다. "로비 공간 루트"를 두 컴포넌트가 따로 저작 참조로 갖는다.
   - 영향
     - 씬 편집에서 이 칸이 비거나 다른 객체로 바뀌어도 연결 검사는 통과한다.
     - 그 상태로 팝업을 열면 코드상 로비 공간 루트를 끄는 단계가 건너뛰어져, 로비 루트가 켜진 채 남는다. 오류도 로그도 없다. 실제로 화면에 로비 방·캐릭터가 3D 판과 함께 보이는지는 카메라 설정에 따라 다르고 **미확인**이다.
     - 이 점에서 `Assets/AGENTS.md`의 "필수 구성 누락은 예외" 규약에 어긋난다.
   - 고칠 방향: `Validate`에서 필수로 던지거나, 저작 참조를 없애고 로비 연결의 루트를 `Configure` 때 넘긴다.
   - 검증: 중간 / 중간

- 읽기 전용 정적 검수였다. 점수 재계산, 중간 6개의 코드 확인, 낮음 표본 5개(M-04·N-09·N-38·N-76·N-82), 범위 124개 대조를 했다.
