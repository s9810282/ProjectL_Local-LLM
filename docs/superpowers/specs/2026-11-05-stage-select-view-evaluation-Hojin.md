## 4 기반 한계(감점 없음)

범위 밖 파일만 가리킨 문제는 없었다. 문제 일부가 기반에 기대는 것은 그 몫을 빼고 판정했다. 예:
- Buffer에 변경 알림이 없어 현재 노드를 폴링하는 것 자체(N-82)
- 증강 진행 판정의 근본 해법(진행 버전 게시)은 Core 요청이 필요(C-04)
- Core `DeckRules`·`TrainingRules`의 내용(C-09·C-29)
- `PopupInputSession`의 "이미 열린 모달" 예외, `UISystem.OpenChildUI`의 부모 미열림 예외는 기반 계약이고, 범위 안 몫은 열기 조건 누락·복귀 누락(C-17·C-15)
- 전투 진입 요청의 Runner 조건은 전투 골격(N-66)

전체 표는 문제 목록 "기반 한계·범위 밖" 절에 있다.
