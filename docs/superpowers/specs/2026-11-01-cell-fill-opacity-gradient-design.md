# Cell Outline 내부 채움 투명도 그라데이션

- 날짜: 2026-11-01
- 요청: 사용자 참고 이미지의 빨간 표시 안쪽 판처럼 보이게 한다.
- 정정: 가장자리 선은 기존 Outline에 있다. 이번 변경은 **안쪽 채움의 투명도 분포**이며 새 선/발광 패스를 추가하는 작업이 아니다.
- 계획: [opacity-gradient-plan](../plans/2026-11-01-cell-fill-opacity-gradient-plan.md).

## 설계

1. 기존 범위 색 RGB, Outline, Merged/EachCell 모양·높이·겹침 순서·위 판에 가려지는 구멍은 유지한다.
2. 채움의 자체 바깥 윤곽 근처는 현재 채움 알파를 사용하고 안쪽으로 갈수록 알파를 낮춘다. 기존 Outline이 밝은 경계선을 맡는다. 배경이 비치는 중앙과 부드러운 안쪽 전이를 만든다.
3. `CombatCellFill.shader`의 기존 `ClusterDistance`와 칸 종류/높이 지도를 재사용한다. Merged에서는 같은 종류·같은 높이 이웃과 이어진 윤곽, EachCell에서는 각 칸의 윤곽을 따른다. 이웃 사이에 별도 선을 추가하지 않는다.
4. 겹친 위 판의 구멍은 기존 알파 마스크를 그대로 적용한다. 구멍 경계를 하위 범위의 새 윤곽으로 취급해 별도 밝은 띠를 만들지 않는다.
5. 머티리얼에 두 값을 둔다. `_EdgeFadeWidth`: 판 한 칸의 축소 후 짧은 변 대비 전이 폭(0~0.45), 0이면 기존 단색 채움. `_CenterOpacity`: 중앙 알파/기존 채움 알파의 비율(0~1). 셰이더 기본값은 0·1로 이전 스타일을 유지하고 운영 `CellFill.mat`만 0.25·0.15로 설정한다. 운영 채움 알파 0.183이면 중앙은 약 0.027이다.
6. 전이 폭을 한 칸의 절반 미만으로 한정해 기존 이웃 기반 거리 계산의 국소 범위 안에서 처리한다. 깊이별 축소와 EachCell 크기도 반영한다. 작은 판에서도 중앙까지 전이가 도달한다.
7. 실제 알파 = 기존 `FieldHighlightPalette.ToFill` 알파 × 윤곽/겹침 마스크 × 중앙 전이 비율이다. `FieldView.fillAlpha`와 색 원본을 복제하거나 덮어쓰지 않는다. 값은 머티리얼 사본에 상속되며 설정 변경은 다음 전투 진입에서 확인한다.

## 구조 점검

- SSOT: 색/전체 알파는 기존 Palette, 모양은 기존 지도/ClusterDistance, 전이 설정은 채움 머티리얼 한 곳. 새 SO/씬 필드를 만들지 않는다.
- SOLID: 입력/범위 계산은 그대로 두고 채움 셰이더가 표현을 담당한다(SRP). 범위 종류별 분기를 추가하지 않는다(OCP). 기존 생성/해제·서비스 계약과 대체 가능성을 바꾸지 않는다(LSP). 설정 두 개만 기존 재질 계약에 추가한다(ISP). Factory/상위 표시 조립에 구체 기능을 추가하지 않는다(DIP).
- JMH/FW: 기존 FieldCellFillStack → 재질 사본/FieldCellFill → Mesh/Color 핸들 경로와 Release 소유자를 유지한다. 서비스 등록/Export/Builder/이벤트 변경 없음. 새 속성 이름·필수 속성/범위 검사는 기존 재질 계약 소유자 FieldCellFillStack에 둔다.
- 기능 독립성: 셰이더·운영 재질·재질 검사만 수정한다. Outline/필드 입력·Core/FieldCamera/Architecture와 사용자가 수정 중인 StageFieldView_Default.asset은 수정하지 않는다.
- 비용: 활성화한 기본 채움도 이웃 종류/높이 지도를 읽어 윤곽 거리를 구하므로 이전 단색보다 픽셀 연산이 늘어난다. 새 텍스처/메시/매 프레임 CPU 생성은 없다. 실제 GPU 비용 측정은 별도 인수 항목이다.

## 검증

- 단일 칸/붙은 사각형/오목 모서리/둥근 모서리/EachCell/축소 판/높이 분리/겹침 구멍을 대조한다. 같은 종류의 내부 칸 경계가 밝은 줄로 드러나면 안 된다.
- 폭 0 또는 중앙 비율 1에서 단색 스타일을 유지하고, 기존 RGB·구멍 마스크를 보존하는지 확인한다.
- 가능한 컴파일·수치 대조와 Unity 셰이더 오류/실제 재생 확인을 구분해 기록한다. 참고 이미지의 조명/후처리 전체를 복제한다고 표현하지 않는다.
