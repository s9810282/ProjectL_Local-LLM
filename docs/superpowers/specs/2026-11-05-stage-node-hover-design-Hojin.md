# 스테이지 노드 호버 강조 설계 — 2026-11-05

## 승인 범위

사용자 선택: 건물 윤곽선, 선택 가능한 호버 노드로 가는 연결선만 강조, 색상·두께·전환 시간 SO 설정.
2026-11-05 추가 승인: 이번 기능은 조회 전용 어댑터에서 Core 공개 `PrepareStageEntry`를 사용한다. Buffer 경유 원칙의 이 기능 한정 예외이며 Core 파일·규칙·현재 위치를 수정하지 않는다.

## 표현

- 가능: 밝은 금색 건물 윤곽선, 현재 노드 → 호버 노드 연결선 강조.
- 불가능: 얇은 회색 건물 윤곽선, 연결선 기본 표시. 기존 제목·설명 호버 유지.
- 현재 위치·클리어 건물 숨김은 기존 정책 유지. 크기 확대·바닥 링은 추가하지 않는다.
- SO에서 가능/불가능 윤곽선 색상·두께, 연결선 강조 색상·두께, 전환 시간(0이면 즉시)을 지정한다. 두께는 기존 메시/맵 로컬 단위를 따른다.
- 맵 드래그·휠·클릭·팝업·이동·표시 교체·해제에서는 호버를 정리한다. 기존 입력 해제 알림을 재사용하며 입력 규칙을 바꾸지 않는다.
- 포인터가 멈춰 있어도 진행 사실 변경을 읽고 가능 상태를 다시 평가한다. 실제 클릭 승인은 기존 Core 경로가 계속 담당한다.

## 대안과 선택

건물 윤곽선 + 연결선(사용자 선택)은 가리키는 대상과 이동 경로가 함께 보인다. 바닥 링은 건물에 가려질 수 있다. 확대/점프는 건물 배치·클릭 범위를 흔들 수 있어 이번 범위에서 제외한다.

## 구성과 계약

- `StageNodeHoverStyleSO` → 불변 `StageNodeHoverStyleData`. `StageMapViewDataSO`가 참조를 갖고 GetData에서 값으로 변환한다. 운영 `StageMapView_Default`에 스타일 에셋을 연결한다.
- `StageNodeAvailabilityReader`: 기존 Core 읽기 API만 어댑트. 대상·현재 위치·클리어·증강 대기·Run 상태가 같으면 이전 표시 결과를 재사용한다. 무효화 가능한 파생 캐시이며 실제 클릭 판정에 사용하지 않는다.
- `StageNodeHoverFeedback`: 기존 설명 표시로 입력 알림을 전달하고 호버 대상·눌림 억제를 소유한다. Tick에서 조회 결과를 표시로 넘긴다.
- `StageNodeOutlineView`: 기존 SelectOutline Scope를 건물 메시별로 빌려 쓰고, 상태 전환/맵 해제 때 반환한다. 원본 메시·머티리얼·공용 Shader는 수정하지 않는다.
- `StageLinkView`: 생성한 연결선별 강조/기본 색상·폭 전환을 소유한다. `StageMapViewDisplay`는 노드·연결선·윤곽선 수명을 조율한다.
- 공용 Render 서비스는 기존 Global → Render → ViewGroup 경로로 받는다. 새 서비스 등록·UIId·화면은 만들지 않는다.

## 원칙 점검

SSOT: 진입 판정은 Core, 진행 사실은 기존 Buffer, 외형 설정은 SO, 호버 입력은 기존 Interaction이다.
SOLID: 판정 어댑터·입력 피드백·윤곽선·선은 각 변경 이유로 분리하고 필요한 의존성만 받는다. 기존 피드백 계약을 유지한다.
JMH/FW: 공용 서비스 재등록 없이 기존 Context를 사용하고 빌린 Scope/Handle은 부모 노드 파괴 전에 반환한다.
독립성: 색/폭 조정은 스타일 에셋 하나, 윤곽선 렌더 변경은 윤곽선 표시 클래스, 조회 방식 교체는 어댑터/조립만 바꾼다. 팝업·전투·카메라 동작 구현과 다른 작업자의 수정 파일은 건드리지 않는다.

## 검증 경계

View 테스트 코드·도우미 작성, MSBuild, Unity 재생은 하지 않는다. 정적 참조·차이·에셋 GUID를 확인하고 컴파일 미확인으로 인계한다.
사용자 Unity 확인: 가능/불가능 호버, 연결선 복원, 빠른 전환, 클릭/드래그/팝업 해제, 챕터 1·2 이동/재진입, 전환 시간 0, 기존 호버 설명, DataBaseAssetTests.

## 2026-11-06 추가 승인 — 진입 가능한 노드의 기본 윤곽선

- 사용자는 호버하지 않아도 **진입 가능한 건물에만** 파란색 윤곽선을 요청했다. 불가능한 건물은 기본 윤곽선이 없고, 호버할 때만 기존 회색을 쓴다.
- `StageNodeHoverStyleSO`의 `Available Node Idle`에서 기본 색상·두께를 지정한다. 호버 시 기존 상태별 색상으로 전환하며 호버 해제 시 기본 파란색으로 복원한다.
- 연결선은 기존처럼 호버한 진입 가능 대상만 강조한다. 팝업·이동·맵 비활성 중에는 기본/호버 강조를 함께 해제한다.
- 최초 맵 표시 때도 포인터 이동을 기다리지 않고 가능 노드를 읽는다. 기존 승인된 읽기 어댑터에 노드별 판정 캐시를 두고, 현재 위치·클리어·증강 대기·Run 상태·맵 재표시가 바뀌면 버린다. Core 판정을 View에서 복제하지 않는다.
- 기본 색상 변경은 SO, 기본/호버 전환은 윤곽선 표시, 판정 재사용은 조회 어댑터에 한정한다. 기존 Render Scope 수명과 서비스 조립은 유지한다.
