# 보호막 Shader Graph 구현 계획

작성: Codex · 2026-10-30

설계: [보호막 Shader Graph 무드 개선](../specs/2026-10-30-defensive-shield-shader-design.md)

## Phase 1 — 그래프와 기본 머티리얼

1. 기존 그래프·머티리얼과 GUID를 보관하고 본체·바닥의 기존 연결을 확인한다.
2. 본체에 얇은 골드 림, 투명 중심, 하단 페이드, 상단 하이라이트, 느린 밝기 호흡을 구현한다.
3. Visibility·Reveal·피격 위치/진행도/강도 입력을 노출한다. 기본값은 유지 상태로 정한다.
4. 바닥을 얇은 접지 링으로 정리하고 기존 머티리얼을 조정한다.
5. 그래프 참조/슬롯/연결 검사와 Unity 임포트·셰이더 컴파일·렌더를 확인한다. 실제 수행한 검증과 제한을 기록한다.
6. Phase 1 결과를 보고하고 리뷰 지점에서 멈춘다.

## Phase 2 — 리뷰 이후 이벤트 연결

- 생성·피격·해제의 실제 호출자, 파티클 수명과 조절값 전달을 먼저 확인한다.
- 표현 수명과 자원 해제를 기존 Render 계약에 맞게 연결한다. 이번 Phase 1에서는 구현하지 않는다.

## 실행 기록

- 시작: 기존 작업 트리에 여러 사용자 변경과 미추적 `BuffeEffect` 에셋이 있다. 기존 변경을 보존하고 대상 그래프·머티리얼만 수정한다. 기존 JMHTest 씬은 저장하지 않는다.

### Phase 1 완료 — 2026-10-30

- 본체: 일반 Shader Graph 노드로 얇은 림·넓고 약한 림·투명 중심·Object 높이 기준 하단 소실·월드 노멀 기준 비대칭 하이라이트·약 2.51초의 밝기 호흡을 구현했다. 기존 네 프로퍼티 참조명과 에셋 GUID를 유지했다.
- 머티리얼 조정: `RimOutLinePower=20`, `RimInLinePower=4`, `RimOpacity=0.45`, `SoftRimOpacity=0.02`, 중심 `BaseColor.a=0.004`. 실제 Game View 확인 후 최초 값보다 두께·밝기를 낮췄다.
- 생성/해제: `_Reveal` 0→1로 아래에서 위로 생성하며 `_Visibility` 1→0으로 전체를 지운다.
- 피격: `_HitPosition`은 Renderer의 Object 공간, `_HitProgress`는 0→1 진행도, `_HitStrength`는 강도다. 파동 반경·폭도 노출했다. 양 끝 진행도에서 파동을 지우며 기본 강도는 0이다.
- 바닥: UV 중앙 기준 얇은 링과 느린 불균일성, 독립 Visibility를 구현했다. **현재 JMHTest 씬에는 바닥 렌더러가 연결돼 있지 않다.** 검증할 때만 임시 Quad로 렌더하고 제거했다. 씬에 새 객체를 저장하지 않았다.
- 그래프는 본체 88개·바닥 32개 일반 노드이며 Custom Function/신규 텍스처/런타임 스크립트는 없다. 연결의 슬롯 방향·중복 입력·순환을 검사했다.
- Unity 6000.0.73f1의 열린 JMHTest에서 두 그래프를 강제 임포트했다. 두 Shader 모두 `isSupported=True`, `ShaderUtil.GetShaderMessages` 오류 없음. 임시 에디터 검증 코드도 Unity 컴파일을 통과했다.
- 실제 Game View 렌더 타깃에서 유지, 숨김, Reveal 0/0.45, 피격 0.15/0.4/0.75/1, 임시 접지 링을 캡처했다. 상태 비교 중에만 머티리얼 복제본에서 호흡을 껐고, 끝나면 원본 머티리얼을 복원했다.
- 픽셀 비교: Visibility 0 = Reveal 0, HitProgress 1 = 유지가 각각 완전히 동일하다. 생성 중간과 활성 피격은 유지와 다르다. 실제 이미지도 확인했다.
- 캡처·검증 기록과 원본 4개 백업은 무시되는 `.utmp/defensive-shield/`에 있다. 최종 유지 캡처는 `after-idle-detail.png`, 바닥 임시 프리뷰는 `after-ground-preview-detail.png`다. 임시 에디터 진입점은 검증 후 제거했다.
- EditMode 테스트는 실행하지 않았다. 영구 C# 변경이 없는 VFX 에셋 변경이며, 해당 Shader Graph를 검사하는 기존 EditMode 테스트는 없어서 그래프 임포트·컴파일·실제 렌더와 경계 픽셀 비교로 검증했다.

**리뷰 지점:** Phase 1을 마쳤다. 실제 생성/피격/해제 이벤트 연결과 바닥 렌더러 배치는 Phase 2에서 호출자·수명을 확인한 뒤 진행한다. 커밋·push는 하지 않았다.
