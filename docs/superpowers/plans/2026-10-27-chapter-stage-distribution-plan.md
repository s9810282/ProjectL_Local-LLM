# Chapter Stage Distribution Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` for a separately authorized implementation, or `superpowers:subagent-driven-development` if the user explicitly selects delegation. Follow the checkboxes and stop after every Phase. This document does not authorize implementation, commits, or pushes.

**Goal:** Guarantee at least one ordinary Shop and one Recovery node per generated chapter map, then select remaining node kinds using designer-controlled SO weights, including graphs with a development stage pin.

**Architecture:** The map SO owns distribution settings; the existing Systems adapter classifies registered stage details into immutable Core pools. Core generates topology, reserves the pinned node and required minimum slots, draws remaining kinds, and selects stage keys. Existing chapter publication owns Buffer installation.

**Tech Stack:** Unity 6000.0.73f1, C#, ScriptableObject authoring, pure Core Contracts/Application, NUnit EditMode.

**Spec:** [Chapter stage distribution design](../specs/2026-10-27-chapter-stage-distribution-design.md).

**Locality guide:** `feature-change-locality-guidelines.md`, a user-supplied local file outside the repository (not linkable for other readers). Its requirements are operationalized in Sections 2, 4, 8, and 9, so implementation does not depend on access to that file.

**Status:** Plan only, 2026-10-27. Source inspected at HEAD `ee931944`; no implementation or tests executed. The design was originally inspected at `6482e073`, before the pin integration described below. Review fixes applied on 2026-10-27 (Section 11); G-API is resolved by user decision.
