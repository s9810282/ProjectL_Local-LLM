# 스테이지 선택 지도 배경 꾸미기

## 요청·설계

- **최신 적용 범위(Phase 5):** 사용자 정정 "모든 프리팹"에 따라 현재 지도 배경 프리팹의 모든 하위 Renderer에 카툰 셰이더를 적용한다. 탁자·양피지·총·칼·랜턴도 포함하며, Phase 4의 제외 규칙을 폐기한다. 이미 적용한 카툰 머티리얼은 그대로 재사용한다.
- **Phase 4 추가 요청:** 지도 위에 배치한 지형·환경 소품에 사용자의 `ProjectL/BaseShader/Cartoon`을 적용한다. 현재 사용자가 직접 추가·수정한 지도 위 환경 오브젝트도 포함하며, 기존 배경 카툰 머티리얼 설정을 따르고 텍스처·기본 색을 유지한다.
- **최신 크기 기준(Phase 3):** 사용자 요청에 따라 돌은 큰 지형 덩어리로 묶고, 선인장·통·상자 등 생활 소품은 지형보다 작게 배치한다. 양피지 위·중앙 보호 영역 유지가 전제다. 이전 Phase의 돌과 소품 크기 비례를 대체한다.
- **최신 사용자 정정:** 환경 사물은 나무 탁자 여백이 아니라 양피지 지도 위에 놓는다. 아래 Phase 1의 탁자 배치는 위치를 잘못 해석한 이력이다. Phase 2에서 소품 30개를 지도 양옆으로 축소·이동하고 중앙 보호 영역은 유지한다. 기존 탁자·지도·총·칼·랜턴은 추가로 변경하지 않는다.
- 사용자 요청: 보유 FBX로 현재 지도 배경을 꾸미되 중앙은 스테이지 노드용으로 비운다.
- 대상: `Assets/ProjectL/Prefabs/StageSelect/Backgrounds/StageMapBackground_Chapter1_end.prefab`.
- 시작 시 이미 수정된 대상 프리팹·StageSelect 씬·FMOD 캐시가 있었다. 프리팹의 현재 내용 위에 배치하고 다른 두 파일은 수정하지 않는다. 시작 프리팹 사본은 `Library/StageMapDressing/before.prefab`.
- 나무 탁자·양피지·리볼버·칼·랜턴을 유지하고, 양옆 여백에 작은 사막 모형을 배치한다. 바위/선인장 군집과 마차/보급품 군집의 크기·간격을 달리한다.
- 중앙 보호 영역은 프리팹 로컬 `x=-6.5..6.5, z=-2.5..26`. 노드 기본 폭 간격 3, 최대 3열과 양피지 크기를 고려한다. 기존 총·칼이 침범하면 가장자리로 소폭 이동한다.
- 새 장식은 `MapEdgeDressing` 부모 아래 기존 FBX의 프리팹 인스턴스로 둔다. 기존 메시·머티리얼·FBX 원본은 수정하지 않는다.
- 런타임/DB/카메라/조립 코드 변경은 없다. 배경 프리팹이 배치의 단일 원본이며 기존 챕터 배경 조회·수명 계약을 그대로 사용한다. 서비스 추가가 없어 FW 등록 계약이나 SOLID 책임 경계 변경도 없다. 다른 기능 수정·검증 없이 이 프리팹만 수정할 수 있다.

## Task 계획 — Phase 1 한 단계

1. 현재 배경과 FBX를 Unity에서 조사하고 미리보기로 재질·형태를 고른다.
2. 왼쪽 사막 군집, 오른쪽 위 보급품 군집, 오른쪽 아래 작은 바위 군집을 배치한다.
3. 위·기울어진 시점에서 중앙 가림과 바닥 접지, 프리팹 참조·누락 재질을 확인한다.
4. 프리팹을 저장하고 결과 미리보기와 검증 기록을 남긴 뒤 멈춘다.

## 실행 기록

- Phase 1 완료. `MapEdgeDressing` 아래 4개 묶음으로 기존 FBX 인스턴스 30개를 배치했다. 왼쪽 협곡·오른쪽 위 마차/보급품·오른쪽 협곡·모서리 세부 소품.
- 기존 총은 x 방향 -2.7, 칼은 +1.6 이동했다. 나무 탁자·양피지·랜턴·조명·루트 변환과 기존 에셋 참조는 유지했다.
- 선인장에 다른 모델의 아틀라스 재질을 적용하면 UV 위치가 달라 붉게 표시돼, 이 배경 전용 무광 녹색 `StageMapCactus.mat`을 추가했다. 원본 FBX·기존 머티리얼은 수정하지 않았다.
- Unity 6000.0.73f1에서 저장된 프리팹을 다시 읽어 검증: 새 소품 30개, 필수 재질/셰이더 누락 0, Missing Script 0, 기존 총·칼·랜턴을 포함해 중앙 보호 영역 침범 0, 루트 identity 유지.
- 위(90도)·사선(65도)·게임 카메라 기울기(54.56도)의 독립 미리보기 렌더를 확인했다. 실제 플레이/노드 생성 화면은 실행하지 않았다. DB·코드 변경이 없어 EditMode 테스트는 실행하지 않았다.
- `Assets/Scenes/StageSelect.unity`의 작업 전후 SHA256이 일치한다. 사용자 기존 씬 변경은 그대로다. FMOD 캐시는 편집하지 않았다.
- 결과 이미지·수치 검증·작업용 에디터 스크립트 사본은 `Library/StageMapDressing/`에 보관한다. 실행용 임시 스크립트와 meta는 Assets에서 제거한다.
- Phase 완료 리뷰 지점에서 멈춘다. 커밋·push하지 않았다.

- Phase 2 완료. 환경 소품 30개를 모두 양피지 지도 위로 옮기고 지도 축척에 맞게 줄였다. 바닥 높이는 0.25, 쌓은 상자만 아래 상자 위로 올렸다.

- 저장 후 재로딩과 위·사선·게임 카메라 기울기 미리보기를 확인했다. 실제 플레이/노드 생성은 실행하지 않았다.
- 이번 정정에서는 기존 탁자·양피지·총·칼·랜턴·루트 변환을 추가로 변경하지 않았다. 씬 파일도 최초 작업 전 SHA256과 일치한다.

## Phase 3 — 바위 지형과 소품 축척

- 설계: 양피지 양옆에 높이 2~4, 길이 3~7의 바위 덩어리를 겹쳐 협곡/암벽 능선을 만든다. 폭은 각 측면 안에서 제한해 중앙 `x=-6.5..6.5`를 유지한다. 기존 바위 FBX 복제와 인스턴스 변환만 사용한다.
- 소품: 선인장 높이 약 0.8~1.25, 통·상자 약 0.4~0.55, 마차 길이 약 1.9. 바위 턱/기슭과 작은 야영지에 묶어 놓는다. 바위 위 소품은 임시 메시 교차 검사로 바닥을 맞춘다. 임시 콜라이더는 저장 전에 제거한다.
- 독립성·FW·SSOT: 변경 원본은 기존 배경 프리팹이다. 런타임/DB/카메라/서비스 조립·Core는 변경하지 않는다. 원본 FBX·재질을 수정하지 않고 별도 런타임 책임도 추가하지 않는다.
- Task: ① 큰 바위 능선 구성 ② 소품 축척/접지 조정 ③ 중앙·양피지 경계/저장 후 재로딩과 렌더 확인 ④ 결과 보고 후 멈춤.
- Phase 3 완료. 기존 바위 6개를 지형 묶음으로 바꾸고 기존 FBX 바위 9개를 더해, 암벽/단차 15개로 왼쪽 능선과 오른쪽 남북 암벽을 구성했다. 지형과 작은 소품을 합쳐 39개다.

- 저장 전후 검증: 중앙 보호 영역 침범 0, 양피지 경계 초과 0, 필수 재질 누락 0, Missing Script 0, 루트 identity 유지, 임시 콜라이더 0. 저장한 프리팹을 재로딩해 위·사선·게임 카메라 기울기 렌더를 확인했다.

- Phase 3 리뷰 지점에서 멈춘다. 커밋·push하지 않았다.

## Phase 4 — 사용자 카툰 셰이더 적용

- 설계: 기존 `Cartoon_Rock_RockT4`의 카툰 표현 설정을 기준으로, 현재 각 원본 머티리얼의 BaseMap·색·노멀·AO·발광·컷아웃을 옮긴 지도 전용 머티리얼을 만든다. 같은 원본은 한 카툰 머티리얼로 공유한다. 외곽선은 작은 소품에서도 형태를 보존하도록 얇게 둔다.
- 적용 직전 조사에서 사용자가 기존 장식을 지우고 루트에 StageSelectRock·식물 FBX 등을 직접 추가한 현재 배치를 확인했다. 사용자의 "여기에 적용"은 이 현재 배치를 가리킨다. 따라서 `SelectStageModel`(기존 탁자/양피지/총/칼/랜턴) 바깥의 환경 Renderer를 대상으로 하며, 이전 Phase의 위치·중앙 침범 기준으로 현재 배치를 고치지 않는다.
- SSOT·독립성·FW: 변환 결과 머티리얼은 이 배경 전용 폴더에 두고 프리팹 참조만 교체한다. 기존 공유 머티리얼·FBX·셰이더/HLSL·렌더 기능·런타임/조립 코드는 수정하지 않는다. 서비스/FW 계약 변경이 없다. 탁자·양피지·총·칼·랜턴은 범위 밖이다.
- Task: ① 셰이더 속성/표면 상태 계약 확인 ② 현재 텍스처·색을 보존해 변환·연결 ③ 저장 후 모든 슬롯/셰이더/텍스처와 렌더 확인 ④ 임시 도구 제거·결과 보고 후 멈춤.
- Phase 4 완료. 사용자가 현재 배치한 환경 Renderer 49개/머티리얼 슬롯 49개에 `ProjectL/BaseShader/Cartoon`을 적용했다. 원본 머티리얼 6종은 각각 한 번만 변환해 `StageMapCartoonMaterials/`에서 공유한다.
- 기존 배경 카툰 기준(명암 2단계, 림/스펙큘러 0)을 복사하고 외곽선 폭을 월드 단위 0.015로 두었다. 색·기본 텍스처·노멀·AO·발광·컷아웃을 현재 원본에서 보존했다. catus01의 3ds Max 셰이더 그래프 대문자 속성도 대응했다(원본 BaseColor 흰색·BaseMap 없음 그대로).

- 저장 후 재로딩 검증: 49개 슬롯 모두 지정 카툰 셰이더 사용, 지원 셰이더/텍스처 참조 정상. 전체 Transform 계층·위치·회전·스케일·활성 상태·메시 참조의 작업 전후 스냅샷이 일치한다. 사용자가 수정한 배치에 이전 지형 검증 기준을 다시 강제하지 않았다.

## Phase 5 — 현재 지도 프리팹 전체 카툰 적용

- 설계: 현재 배경 프리팹의 비활성 자식과 중첩 FBX/프리팹을 포함한 모든 Renderer·모든 머티리얼 슬롯을 대상으로 한다. 카툰이 이미 적용된 슬롯은 재사용하고 나머지 슬롯만 텍스처·색·표면 설정을 보존해 변환한다.
