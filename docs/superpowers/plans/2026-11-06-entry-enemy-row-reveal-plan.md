# 전투 진입 적의 그리드 Y 행별 등장 — 설계·Task 계획 (2026-11-06)

사용자 요청: 맵 진입에서 적이 동시에 소환되는 대신, 그리드 Y 기준 맵 끝의 유닛부터 라인별로 순차 등장한다.

## 설계

- 기존 첫 필드 적 수집에서 Buffer 캐릭터 사실의 Anchor.Y를 함께 받는다. 월드 높이·화면 위치로 행을 추정하지 않는다. 큰 Y부터 작은 Y 순서이며, 다칸 유닛은 Anchor.Y 하나에 속한다.
- 같은 Y의 적은 같은 시점에 기존 소환 상승 연출을 시작한다. 적이 있는 행만 순번을 부여해 빈 행에서 추가로 기다리지 않는다. 다음 행은 앞 행의 완료를 기다리지 않고 설정한 간격 뒤 시작한다.
- 전역 전투 연출 SO에 Enemy Entry Row Gap Seconds=0.2를 둔다. 유한한 0 이상이며, 0이면 기존 동시 등장이다. 기존 소환 대기·상승 시간·깊이·회전 수는 재사용한다.
- 새 CombatEntryEnemyRows는 Y 목록과 간격으로 대상별 시작 지연만 계산한다. BoardEntry는 대상/행 수집과 연결만 한다. 기존 CombatEntryRiseAppearance는 선택적인 대상별 시작 지연을 받아 CombatPieceStart.AtStart(delay)에 넘긴다. 구조물은 지연 없이 기존대로 시작한다.
- 각 모델은 해당 상승 조각이 시작해 아래쪽 자세를 적용한 직후 공개한다. 대기 중인 행은 모델/HUD를 숨긴다. 기존 조각 실행이 시간·완료·취소를 소유하고, 별도의 타이머나 코루틴을 만들지 않는다. HUD와 상시 효과의 기존 전체 완료 공개 정책을 유지한다.
- 전체 진입은 마지막 행의 상승까지 기다린다. 중간 취소·실패·재진입에서는 시작하지 않은 행도 기존 표시/HUD 복구 대상이며, 자세 대여·세대·재사용 가드를 유지한다. Nexus 착지 눌림과 기존 보드/선로/구조물 순서는 변경하지 않는다.

SSOT: 필드 적 선택/좌표는 기존 수집과 Buffer 사실, 간격은 전역 SO, 상승 곡선은 기존 CombatRisePiece, 시간은 CombatPieceRun이 소유한다. S/O: 행 순서 계산을 전용 부품에 두고 공유 상승은 시작 시점 입력만 확장한다. L: 구조물의 기본 지연 0과 완료/취소 계약을 보존한다. I: 행 계산은 Y 목록/간격만 받는다. D: 기존 Factory가 설정을 주입하고 신규 전역 조회가 없다. FW/JMH: 기존 자세 채널 대여/반납 경로를 사용하며 새 서비스·등록·Export·MonoBehaviour·코루틴을 만들지 않는다. 기능 독립성: 행 간격/순서 변경은 전용 계산과 설정에 머무르며, 보드/선로/Nexus 구현을 읽거나 수정할 필요가 없다. 공통 경계인 상승 준비/시작/취소는 구조물 지연 0까지 정적으로 대조한다. Core·FieldCamera·Architecture 수정 없음.

검증: View 작업 규약에 따라 Test 코드 작성/수정·시험 실행·MSBuild·Unity 실행은 하지 않는다. **컴파일 미확인**으로 보고한다. Unity에서는 입력 순서와 무관한 큰 Y→작은 Y, 같은 행 동시 시작, 빈 행 건너뛰기, 다칸 Anchor 기준, 행 간격 0/조정, 0명/한 행, 대기 중 모델/상시 효과 숨김, 마지막 행 완료 뒤 입력 가능, 중간 취소·재진입 및 일반 구조물/Nexus 유지 여부를 확인한다. 설정 에셋 변경으로 DataBaseAssetTests는 사용자 확인 항목에 포함한다.

## ER1 결과

적 수집이 기존 대상과 같은 순서로 Anchor.Y를 반환하고, Factory가 간격을 주입한 CombatEntryEnemyRows가 중복 Y 제거→내림차순 정렬→행 순번×간격으로 대상별 지연을 만든다. 예를 들어 Y가 7·7·4·1이면 시작 지연은 0·0·0.2·0.4초다. 비어 있는 Y=6·5·3·2 때문에 시간이 늘어나지 않는다. 기존 입력 목록의 순서와 무관하며 다칸 유닛은 기준 칸 행에 한 번만 들어간다.

공유 상승은 선택적인 시작 지연 목록의 개수/유한한 0 이상 조건을 숨김 전에 확인해 복사한다. CombatPieceStart.AtStart에 지연을 전달하고, 내부 VisibleRisePiece는 기존 CombatRisePiece.Begin의 아래쪽 자세 적용 직후 해당 모델만 공개한다. 조각의 시간·회전·상승·완료 판정은 그대로 위임한다. 구조물은 지연 목록을 전달하지 않아 전부 0으로 시작한다. 모든 항목에 waits=true를 유지하며 지연 중 항목도 전체 완료에 포함된다.

정적 검토: 수집/생성자/Prepare 호출을 검색해 대조했고, 기존 CombatPieceRun의 지연 후 잔여 프레임 시간 전달·모든 항목 완료 뒤 자세 반환·취소 때 대여 반환을 확인했다. 진입 Cancel은 시작 여부와 무관하게 모든 표시/HUD 스냅숏을 복구하고 지연 목록을 비운다. 적이 0명이면 즉시 완료, 한 행/간격 0이면 동시 시작이다. 행 순번×간격의 넘침도 기존 수 검증으로 거절한다. 신규 .meta와 UTF-8/LF·diff 공백을 확인한다.

설계의 SSOT/SOLID/FW·JMH/기능 독립성을 유지했다. Factory의 조립 변경은 행 계산 부품/설정 주입에 국한됐고, 새 서비스 등록·Export·공개 API·전투 중 소환 조각 구현·Core 변경은 없다. 기존 Nexus 착지 눌림과 FieldUnitPresenter의 병행 Unit Action Cursor 변경은 보존했다. Test 코드 작성/수정·시험 실행·MSBuild·Unity 실행 없음. **컴파일 미확인**, 위 Unity 인수와 DataBaseAssetTests 확인 대기다.

조정 위치: CombatPresentationSettings_Default → Combat Presentation Settings Data → 전투 진입 적 행별 등장 → Enemy Entry Row Gap Seconds. 기본 0.2초이고 0이면 기존 동시 등장이다. 기존 Summon Rise Delay Seconds/Seconds/Depth/Turns는 그대로 사용한다.
