# 맵 배경 구역 분할 도구 — 설계·Task 계획 (2026-11-03)

사용자 요청: 앞서 StageTest/NewStageTest에 수행한 X·Z 구역 분할을 반복해서 사용할 Unity 에디터 도구로 만든다.

## 설계

- 메뉴 `ProjectL > 맵 배경 구역 분할`. 일반 맵 프리팹을 Prefab Mode로 열고, 기존 `DayMap/BackGroundProp`을 대상으로 미리보기 후 적용한다. 구역 크기는 기본 16이며 사용자가 바꾼다. Scene 뷰에는 점유 구역 테두리, 창에는 구역별 소품 수를 표시한다.
- 구역 인덱스는 배경 루트 기준 X/Z 피벗을 크기로 나눈 floor, 중심은 `(인덱스 + 0.5) × 크기`, Y=0이다. 메시를 자르지 않고 소품 루트를 재부모화한다. 미리보기 이후 위치·계층·옵션이 바뀌면 다시 확인해야 한다.
- 기본적으로 직속 소품을 한 덩어리로 보존한다. `풀어낼 빈 부모 이름`(초기 Map, Props, rock)에 해당하는 Transform 전용 부모만 재귀적으로 풀어낸다. 풀어낼 부모는 활성·회전 항등·크기 1이어야 하며, 위치 오프셋은 소품 위치에 누적한다. 빈 부모 자체는 남긴다. 이미 있는 직속 RevealArea는 같은 조건으로 펼쳐 재분할한다.
- 중첩 프리팹 루트는 내부를 분해하지 않는다. 카메라/조명이 들어 있는 소품 묶음은 제외하여 기존 위치를 유지한다. 기존 RevealArea 안에 제외 대상이 있으면 구역 이동의 영향을 피하기 위해 구성 오류로 거절한다. FBX/Variant나 중첩 프리팹 내부의 구조 편집은 지원하지 않으며 Unpack으로 우회하지 않는다.
- 기존 구역 이름을 재사용하며, 재분할 후 비어 있고 사용하지 않는 이전 RevealArea만 제거한다. 일반 분류용 빈 부모는 보존한다. 이전 구역 내부의 빈 부모/비시각 보조 오브젝트는 배경 루트로 꺼내 같은 위치에 남긴다. 위치·회전·크기·활성 상태와 중첩 프리팹 연결을 유지하고, 새 구역만 Transform/GameObject로 만든다.
- 적용은 Unity Undo 한 그룹이다. 예외는 해당 그룹을 되돌리고 원인을 창에 표시한다. 저장은 Prefab Mode의 저장/Auto Save 정책을 따른다. Ctrl+Z/Redo를 지원하며 도구가 에셋을 직접 덮어쓰거나 프로젝트 프리팹을 자동 분할하지 않는다.

## 구조 점검

경로/접두사는 새 `Tool.Runtime.MapRevealAreaLayout` 한 곳을 Editor와 기존 런타임 수집기가 공유한다. 두 어셈블리 모두 기존 Tool.Runtime 참조가 있으므로 asmdef를 바꾸지 않는다. 분할 읽기/계획은 MapRevealPartitionPlan, Undo 적용은 MapRevealPartition, 표시/조립은 MapRevealPartitionWindow가 담당한다. 이미 동작하는 연출·타일 시간표는 변경하지 않는다.

SSOT: 경로/이름 계약과 읽기 계획을 공유하고 미리보기·적용이 같은 수집을 사용한다. S/O: 편집 UI·분류·변경 적용 책임을 분리하며 기존 런타임 동작을 재사용한다. L: 기존 RevealArea 수집/취소 계약 유지. I: 좁은 계획과 Transform만 소비한다. D: 창이 대상/설정을 전달하며 새 서비스 조회를 만들지 않는다. FW/JMH: 새 서비스 등록·Export·Builder·게임 UI 없음. EditorWindow는 게임 런타임 UI가 아니다. 기능 독립성: 구역 크기/수집 변경은 편집 도구 안에, 등록 경로 변경만 공유 계약과 소비자에 영향을 준다. Core·FieldCamera·Architecture·다른 맵 도구는 수정하지 않는다.

## 사용법

1. Project 창에서 맵 프리팹 선택 → `ProjectL > 맵 배경 구역 분할`.
2. `프리팹 열기`로 Prefab Mode에 진입한다. 이미 열려 있으면 `현재 프리팹 사용`을 누른다.
3. `구역 크기`를 지정하고 `구역 미리보기`를 누른다. 현재 StageTest/NewStageTest는 16을 기준으로 정리돼 있다. Scene 뷰에서 테두리, 도구 창에서 구역별 소품 수를 확인한다.
4. `분할 적용`. 수정은 Prefab Mode의 저장/Auto Save 설정을 따르며 Ctrl+Z/Redo로 되돌릴 수 있다.

`풀어낼 빈 부모 이름`은 쉼표로 구분한다. 초기값 Map, Props, rock은 앞선 StageTest 정리와 같은 분류용 부모다. 다른 이름의 소품 묶음을 풀어내려면 여기에 이름을 추가한다. 빈 문자열이면 기존 RevealArea만 펼치고 그 밖의 소품 내부는 통째로 유지한다. 크기 변경 후 재분할도 같은 순서다. 카메라/조명 포함 묶음은 제외 목록에 표시되며, 구성 오류는 적용 전에 창에 원인과 대상을 표시한다.

## RT1 결과

코드·정적 검토 완료. 새 .cs/.meta 4쌍과 기존 수집기의 상수 참조만 변경했다. 어셈블리 참조는 Tool.Editor→Tool.Runtime, Systems→Tool.Runtime의 기존 연결을 사용하며 공유 타입은 UnityEditor에 의존하지 않는다. 기존 경로/접두사 문자열과 런타임 동작은 동일하다. 새 서비스·Export·등록·게임 UI가 없다.

수집/적용 전에 경로·프리팹 유형·중복 구역 이름·부모 구성·유한한 좌표·인덱스 범위를 검사한다. 미리보기의 계층·자세·활성/이름 스냅샷과 적용 직전 새 계획을 대조하며, Unity 계층/Undo 수정 이벤트에서도 미리보기를 무효화한다. 창 종료 시 모든 구독을 해제한다. 기존 구역 재사용, 불필요한 빈 구역만 제거, 보조 오브젝트 보존, 원본 자세 재적용, 중첩 프리팹 오버라이드 기록과 실패 시 Undo 복구 경로를 소스로 검토했다. 창에서 프리팹을 여는 Unity GUI 종료 예외는 오류 표시로 가리지 않는다.

설치된 Unity 6000.0.73f1의 API XML과 기존 에디터 도구를 참고해 Prefab Mode/Undo/Handles 호출을 대조했다. .meta GUID 고유성·UTF-8/LF·diff 공백 확인 완료. 실제 에셋을 분할 실행하거나 Unity를 호출해 검증한 것은 아니다. Test 코드/시험 실행/MSBuild 없음. **컴파일 미확인**, 위 Unity 인수는 사용자 확인 대기다.
