## 실행 기록

- 2026-11-02: 구현 전 설계·Task 계획 작성. 기존 사용자 작업 트리와 별도 기믹 호버 범위 문서는 수정 범위에서 제외한다.
- Phase 1 완료: `FieldArrowhead`가 삼각형 메시 생성·자세·색·핸들 해제를 소유하고 세 표시가 이를 사용한다. 이동 경로의 띠 조립·끝 줄이기 식은 변경하지 않았다. 넉백은 최대 사용 수만큼 화살촉을 재사용하며, 첫 표지는 Build 때 숨겨 만들어 잘못된 재질을 일찍 거절한다.
- 기본 에셋 두 개는 기존 Arrow 재질 `Bullet.mat`(GUID `57f974494f6a435889f224efa2302097`)을 사용한다. 길이 0.5·너비 0.8로 현재 이동 경로 화살촉과 크기를 맞췄고 넉백 높이 0.25·토네이도 월드 높이 0.05를 유지했다. 토네이도 색은 재질, 넉백 색은 기존 FieldView 상태별 팔레트가 정한다.
- 조립 추적: 기존 Global Render → `CombatDisplayServices.Meshes/Colors` → 운영·특성 미리보기 Factory → `FieldTornadoPresenter` → 공용 화살촉. 넉백은 같은 서비스를 기존 `FieldView.Build`에서 받는다. 서비스 등록·Export·Builder·Core 변경 없음.
- 정적 점검: 작업 파일 `git diff --check` 통과. Assets 전체의 이전 프리팹 필드·접근자·삼각형 계산 참조 잔여 0건. 새 스크립트 GUID 중복 없음, 기존 Arrow 프리팹·meta 존재 확인. 길이·너비와 재질 참조, 구성 실패·반복 해제·전체 해제 경로를 확인했다. 이동 경로의 이전 자세 식과 공용 자세 식은 동일하다. 작업 파일은 UTF-8·LF이며 U+FFFD 없음.
- 동시 작업: `FieldView` 등에 별도 기믹 호버 범위 변경이 진행 중이며, 해당 내용은 유지했다. 이번 범위에서는 화살촉 연결 부분만 수정했다.
- **컴파일 미확인**. Test 코드·MSBuild 실행·커밋·push 없음. Phase 1 리뷰 지점에서 멈춘다.
- Phase 2 완료(2026-11-02 사용자 높이 설정 요청): 토네이도 SO의 `directionArrowLift` → 불변 Data의 `DirectionArrowLift` → Refresh·경고 갱신 두 배치 호출에 연결했다. 기본 에셋 0.05로 기존 높이를 유지하고, 음수·NaN·무한대는 Data 생성에서 거절하며 0은 허용한다. 넉백은 기존 높이 설정 0.25와 `FieldKnockbackMarkers` 연결을 확인했다. 기존 토네이도 높이 상수 제거, 생성자 호출은 SO 한 곳에서 인수 일치, 작업 파일 `git diff --check` 통과. 공용 그리기·이동 경로·Factory·Core·Test 코드 변경 없이 Phase 2 리뷰 지점에서 멈춘다. **컴파일 미확인**.
