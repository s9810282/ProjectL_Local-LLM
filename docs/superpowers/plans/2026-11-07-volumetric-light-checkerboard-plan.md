## Phase 1 후속 — D3D11 정수 연산 경고 수정

- 사용자 제보: CSComposite의 Compute 90행 signed integer divide/modulus 성능 경고.
- 원인: 두 커널이 공유하는 GetShadowAttenuation의 atlas 좌표 계산에 `cascade % 2`, `cascade / 2`가 남아 있었다.
- 수정: 음수 cascade를 먼저 반환한 다음 uint로 변환하고 `& 1u`, `>> 1u`를 사용한다. 유효 인덱스 0~3의 타일 좌표 (0,0)/(1,0)/(0,1)/(1,1)는 동일하다. 두 커널 모두 같은 수정 함수를 사용한다. 빛 방향·효과·짝수/홀수 분할 방식 변경 없음.
- 정적 연산 대조와 diff 공백 점검 완료. **컴파일 미확인**, 경고 소멸은 사용자 Unity 재임포트에서 확인해야 한다. Test 코드·MSBuild·Unity 컴파일/Play 실행 없음.
