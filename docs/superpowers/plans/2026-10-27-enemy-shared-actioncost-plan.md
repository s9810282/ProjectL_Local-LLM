# 적 공용 행동 코스트 Task 계획

설계: [적 공용 코스트](../specs/2026-10-27-enemy-shared-actioncost-design.md).
2026-10-27 사용자 확정: 최대 10, 공격비 부족 시 이동 시도, Core 수정 허용, 검증 생략 후 실행.

## Phase E1 — 실행 경로 일괄 연결

계약만 먼저 바꾸면 기존 무예산 설치 검사와 충돌하므로 상태·계산·Buffer를 한 Phase로 연결한다.

- E1.1 EnemyTurnRules(10)·EnemyActionBudget 및 .meta 추가.
- E1.2 CombatCommandState의 생성·With·SameValues에 EnemyBudget 추가. 운영 상태 복사 경로 보존.
- E1.3 EnemyBudget funding·정산 스냅샷·공통 자금 검사·이동 비용 응답 연결. 무료 반응 유지.
- E1.4 적 시작 충전, 이동/공격 정산, Buffer의 준비·시작·진영별 지출/보존 불변식 연결.
- E1.5 기존 EntityId 순회·공격 실패 후 이동·행동 불가 시 종료 경로 유지. AI 정렬 수정 없음.
- E1.6 설계 확정 반영·Core 경계 인계·실행 상태 기록 후 멈춰 보고.

## Phase E2 — 검증 (사용자 지시로 생략)

설계 §6의 순수 계산·Buffer 통합 회귀 및 Unity 컴파일/EditMode/재생 확인은 이번에 실행하지 않는다. 무예산 정책을 전제로 한 기존 테스트 기대값도 미갱신으로 남긴다. E1 코드 완료를 검증 완료로 보고하지 않는다. 향후 검증 재개 시 기존 테스트 fixture에 적 예산을 명시하고 정책 기대값을 함께 갱신한다.

## 실행 기록

- E1: 코드 반영 완료. 리뷰 지점에서 정지. 테스트·컴파일·재생 검증 완료를 의미하지 않음.
- E2: 사용자 요청으로 생략. 테스트·빌드 명령 실행 없음.
- 기존 미커밋 변경은 보존하며 커밋·push하지 않는다.
