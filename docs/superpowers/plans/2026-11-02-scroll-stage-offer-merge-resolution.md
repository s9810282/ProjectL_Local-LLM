## 설계와 범위

- 충돌 6개: DeckEditUI/StageOfferUI 프리팹, StageOfferLayoutView/ShopPopupController, TMP 폰트 2개.
- 덱 Rider 머티리얼과 슬롯 활성 상태 override를 모두 보존한다.
- 이벤트 계층은 `두루마리 ContentFrame → 카드 스크롤 Viewport → Cards → 카드 7개`로 합친다. 제목·골드·나가기·오류 표시는 같은 ContentFrame 안에 둔다. 양쪽 프리팹 객체와 참조를 유지한다.
- 숨김 때 두루마리 초기화와 카드 스크롤 위치 초기화 상태를 모두 정리한다. 상점은 닫힘 대기 중 제출 차단과 훈련 단계 직후 입력 잠금을 함께 유지한다.
- 폰트는 양쪽의 문자·글리프를 보존한다. 현재 브랜치 아틀라스의 기존 배치는 유지하고 상대 브랜치에만 있는 글리프의 SDF 픽셀과 메트릭을 빈 공간으로 옮겨 병합한다. 문자→글리프→영역 연결과 패킹 여백·빈 영역을 함께 갱신한다. 원본 font/Material/Texture fileID·GUID·아틀라스 크기는 유지한다.
- SSOT/SOLID/FW: 기존 연출 진행도와 기능 상태의 소유자를 바꾸지 않는다. 새 서비스·UIId·입력 경로를 추가하지 않고 프리팹 조립과 충돌 부분만 수정한다. Core/카메라/Architecture 및 자동 병합된 다른 기능은 수정하지 않는다.
